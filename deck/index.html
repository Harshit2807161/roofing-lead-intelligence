Options considered

We chose B: let the LLM read, let code rank

OptionWhat it buysWhat it costs
A
Score, then write		Simplest; one promptRank is blind to the free text (trades, staff, activity)
B · chosen
Extract, score, write		Rank sees text signals, but stays code-owned and explainable; extraction is measurable field by fieldTwo prompts; an extraction error can move a rank (visible in the breakdown)
C
Research the top N on the web		Real owner namesLeaves GAF data; harder to test. Our next step, with Perplexity

Rejected: an LLM that scores leads directly. Unstable, unexplainable, untestable.

Failure modes

What breaks, and what catches it

If……then
GAF rotates its key or blocks usThe run fails loudly (count check); raw files let us re-parse without re-fetching
The model misquotes or invents a personVerbatim check drops the signal; validator rejects the insight, one retry, else "needs review"
A review contains instructionsTreated as data; chat tools are read-only, so there's nothing to send or write
The chat loops or stallsBudgets on steps, tool calls and time, then a forced answer; 40 s timeout
The answer isn't in our dataIt says so ("That isn't in our data") instead of guessing

Future considerations
